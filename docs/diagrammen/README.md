# Diagrammen

Deze map bevat PlantUML diagrammen die de processen en flows binnen de CineApp visualiseren.

## Beschikbare Diagrammen

- [Bestelproces](bestelproces.puml): Het volledige proces van stoelselectie tot betaling en ticket
  download.
- [Registratie Proces](registratie_proces.puml): De flow van gebruikersregistratie via de
  `AccountComponent`.
- [Navigatie Flow](navigatie_flow.puml): Hoe de `RootComponent` en Decompose navigatie tussen tabs
  afhandelen.
- [Film naar Bestellen Flow](film_naar_bestellen_flow.puml): De navigatieketen van het thuisscherm
  naar de uiteindelijke bestelpagina.

## Hoe te bekijken

Deze bestanden kunnen worden bekeken met de PlantUML plugin in Android Studio of door de code te
kopiëren naar de [PlantUML Online Server](https://www.plantuml.com/plantuml/).
